## 🚀 Quick Start

### Option 1: Direct File Open
1. Simply open `index.html` in any modern browser
2. No server required for basic viewing

### Option 2: Local Server (Recommended)
```bash
# Python 3
python -m http.server 8000

# Node.js (with http-server)
npx http-server

# PHP
php -S localhost:8000
```

Then visit: `http://localhost:8000`

## 📝 Customization Guide

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary: #6366f1;
    --secondary: #8b5cf6;
    /* ... more variables */
}
```

### Update Content
All content is in `index.html` - edit directly, no build process.

### Add Sections
Copy any `.section` div and modify content.

### Modify Features
Edit the `.features-grid` in HTML and add/remove `.feature-card` elements.
